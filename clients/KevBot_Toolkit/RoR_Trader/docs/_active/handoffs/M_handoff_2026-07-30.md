## TRAPS THAT COST REAL TIME
1. **`git merge --ff-only` refuses SILENTLY** when an untracked local file collides with one
   newly tracked on dev — it prints "Updating x..y" and aborts, and reading only the last
   line hides it. **Three times on 07-30.** Check the pull actually moved HEAD.
2. **Stale-base diffs lie.** `git diff origin/dev <branch>` on a fork-behind branch shows huge
   phantom deletions. Use `git show --stat <sha>`. Fooled a first glance **four times**.
3. **A merge can break a TEST rather than the code** — three times. Always run the FULL suite
   set after a reconcile, never trust a docstring-only diff to be inert.
4. **Moving an ARMED task's status has dispatch consequences.** Staged→Review un-refused #195
   and it dispatched into an M-reserved step. Disarm before re-statusing.
5. **`pgrep -af <pattern>` matches your own argv** — including a dispatched agent's whole
   prompt. This produced a live false GREEN in preflight (9). Use the bracket trick AND check
   the process shape.
6. **M's hand-ticks are lower fidelity than the endpoint's** — a PostgREST PATCH sets `done`
   but skips `completed_at`/`completed_by`/hand-off. Prefer `/steps/complete`; see #217.
